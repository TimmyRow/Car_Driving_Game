# Shared implementation contract

Project: Velocity Coast, original premium coastal arcade racer in Three.js/Vite/TypeScript. No existing workspace games touched.

Root owns main.ts, style.css, track.ts, UI, audio, rendering pipeline, camera, integration. World agent owns world.ts and car.ts only. Simulation agent owns simulation.ts and tests only. Reviewer owns qa/ notes and captures only.

Track module root provides `trackLength: number`, `roadHalfWidth = 9`, `sampleTrack(distance:number, lateral=0): {x:number,y:number,z:number,heading:number,curvature:number}`, and `trackPoints: {x:number,y:number,z:number}[]`. Heading atan2(dx,dz); forward local +Z, right local +X. Track is closed; all distances wrap. Main will create world through `createWorld(): THREE.Group`. World imports sampleTrack, trackLength, roadHalfWidth from ./track. Asphalt top sample y; car root placed y+0.02. World builder includes physical track meshes, shoulders, markings, barriers, terrain, water, mountains, palms, detailed buildings, start/finish gantry. Must not set scene lighting/camera itself. Export optional `updateWorld(time:number):void` only if animation desired.

Car factory `createCar(color: string): THREE.Group` forward +Z, footprint ~2.05 x 4.55, wheel radius .39, floor y=0. Car root.userData.wheels = THREE.Object3D[], root.userData.frontWheels optional, root.userData.brakeLights optional material[], root.userData.flames optional THREE.Object3D[]. Original sculpted supercar, smooth bevelled body, glass, detailed wheels, head/taillights, no licensed marks.

Simulation module exports `createSimulation():Promise<Simulation>`. Types: `Controls {steer:number;throttle:boolean;brake:boolean;nitro:boolean}`. `RaceMode='race'|'time-trial'`. `Vehicle {id:number;name:string;color:string;distance:number;offset:number;speed:number;yaw:number;drifting:boolean;boosting:boolean;nitro:number;finished:boolean}`. distance unwrapped traveled from start grid; yaw relative road direction; speed m/s; nitro 0..1. `Simulation {player:Vehicle; rivals:Vehicle[]; phase:'ready'|'countdown'|'racing'|'finished';elapsed:number;countdown:number;position:number;lap:number;totalLaps:number;bestLap:number;lastLap:number;driftScore:number;impact:number;reset(mode?:RaceMode):void;start():void;step(dt:number,input:Controls):void;dispose():void}`. Root drives fixed 1/60 sec simulation. Pause by no step. At least 2 laps race, one time trial. Uses Rapier for meaningful collisions as skill requires; arcade road-coordinate movement acceptable. AI no unavoidable blockers, speed offers attainable win. Nitro replenishes driving+drifting. Start countdown 3 sec. Root separately samples track position for vehicles. Race final independent stats exposed through fields. Keep simulation free of DOM and THREE objects.

Aim polished cohesive coastal art, cream/off-white + vivid acid yellow branding, dark ink UI, readable sparse race HUD. Browser fast boot; all assets locally bundled. Honest review against actual official Asphalt screenshots; no unsupported AAA or blind-test claims. Review loop concrete defects, not subjective endless perfection.

## Wayfinder expansion

`track.ts` now exports `TRACKS:TrackDefinition[]`, `getTrack(id)`, `selectTrack(id)`, and the live `activeTrack`, `trackLength`, `trackPoints` bindings. The legacy `sampleTrack` uses the active route. IDs are `riviera`, `canyon`, `alpine`; each definition includes immutable `points`, `length`, `sample`, metadata and lighting. Select a track only outside racing, then rebuild/reset the simulation. Root caches at most three world groups and shares the world asset textures.

`Simulation.reset(mode?,difficulty?,laps?:1|2|3)` supports career lap counts. Soft and sustained boosted contact never escalates automatically; only strong relative rear/lateral impacts wreck. The cinematic crash API remains unchanged.

`career.ts` owns nine event definitions, safe save normalization, idempotent best-medal rewards, chapter gates and cosmetic unlocks. Root main.ts owns route/career menus, lighting changes and local persistence. Career event difficulty overrides Quick Race Settings only for that event. No remote account or currency service is required.
